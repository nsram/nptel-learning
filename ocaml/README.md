# OCaml Browser Notebook

An independent browser-based companion for the public OCaml NPTEL course.

## Current pilot

- `notebook.html` — blank OCaml 5.4 browser notebook application.
- `notebooks/M01-first-steps.ocamlnb` — introductory sample notebook.
- `notebooks/Pilot-feedback.ocamlnb` — structured tester feedback and issue report.
- `index.html` — learner-facing instructions and download links.

The application and course notebooks are deliberately separate. Updating the application should not require rewriting compatible `.ocamlnb` files.

## Trying the sample

1. Launch or download `notebook.html`.
2. While connected, wait for **OCaml 5.4 ready offline**.
3. Download `M01-first-steps.ocamlnb`.
4. Select **Open** in the notebook application and choose the downloaded file.

## Reporting pilot issues

Download and open `Pilot-feedback.ocamlnb`, complete the relevant sections, save it under a descriptive filename, and attach it to a reply in the class Google Group.
