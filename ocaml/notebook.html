Using the notebook

The first launch downloads the pinned OCaml 5.4 runtime. After the green Ready offline indicator appears, the runtime is stored in this browser.

  • Shift + Enter: run or render the current cell, then move to the next cell.
  • Ctrl/⌘ + Enter: run or render the current cell and stay there.
  • Running a code cell automatically runs any required earlier code cells.
  • Notebook source is autosaved locally. Save updates a file previously selected with Save As when possible; otherwise it downloads a portable .ocamlnb copy.
  • Save As suggests a lowercase, hyphenated filename based on the notebook title and, when supported, lets you choose its folder.
  • The source line beneath the title shows the notebook file most recently opened or selected with Save As.
  • For privacy, browsers provide the filename but not the file's full folder path.
  • Close unloads an opened notebook and returns the app to an empty notebook. It does not delete the .ocamlnb file.
  • Open Notebook loads a previously downloaded .ocamlnb file.
  • Export HTML creates another copy of this notebook with its current cells embedded.
  • Stop terminates a long-running program, preserves the cells, and restarts OCaml.

Core OCaml and its standard library are available. Additional OPAM packages are not included.

Browser execution and editing are provided by x-ocaml.
