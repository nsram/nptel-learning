# Interactive Learning Companions

Independent interactive companion materials for selected NPTEL courses, including browser-based notes, exercises, quizzes, and coding tools.

## Available materials

- [OCaml](ocaml/) — browser-based OCaml notebook and interactive course exercises.
- Mathematical Foundations of Generative AI — planned.

## Publish with GitHub Pages

1. Create a public GitHub repository named `nptel-learning`.
2. Upload the **contents** of this directory to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.

The expected project URL is:

```text
https://YOUR-GITHUB-NAME.github.io/nptel-learning/
```

No build step or GitHub Action is required.

## Local test

Serve the repository root with any static web server and open `/ocaml/`. Directly opening the landing pages as local files also works, but a local server more closely matches GitHub Pages.
